Quick Start

  1. Position your iPhone. Secure it where it has a clear view of the sky. Your body, a pocket, or surrounding structures can obstruct GPS reception. Set up the phone before riding.
  2. Allow location access. Allow Lap Doctor to use your location. For recording with the screen locked, enable the required background/Always location access and Precise Location when requested. If access is missing, follow the app's permission prompts.
  3. Check Setup. Start with a launch confirmation speed of 20 mph and a stop duration of 3 seconds. Choose 0 minimum completed laps for your first test so partial laps and straight runs can be recorded.
  4. Create an event. Open Events, tap + CREATE NEW EVENT, check the date, enter a place or event name, and add optional event notes. Tap OK.
  5. Arm the event. Open the event and tap ARM RECORDING READY.
  6. Remain stationary. Stay stopped for the selected stop duration. Wait until the app is ready for launch.
  7. Launch and ride. Accelerate beyond your launch confirmation speed. Lap Doctor confirms the launch and calculates timing back to the beginning of the launch. It establishes the start line automatically from your stationary starting position.
  8. Complete your laps. Cross the automatically established start line in the same direction as your launch. Recording continues as laps are completed. The app can record with the screen locked when the required location permissions are enabled.
  9. Stop to finish the session. Remain stopped for the selected stop duration. Lap Doctor closes the session and prepares for another launch. You can ride another session without manually starting a new recording.
  10. Disarm and review. When finished, tap DISARM. Open a saved session with VIEW to see its results, edit notes or the session name, or remove unwanted laps from the displayed results.

How to…

Choose a task to open its instructions.

Create an event

An event groups recordings from a practice day, race meeting, or other outing.

  1. Open Events.
  2. Tap + CREATE NEW EVENT.
  3. Check or edit the date.
  4. Enter the place or event name.
  5. Add optional event notes, such as general track conditions or the day's setup.
  6. Tap OK.

An event must have a name. Creating an event does not begin recording; arm it when you are ready.

Find an existing event

Open Events. Newest events appear first. Scroll down to find older events, then tap VIEW beside the event you want.

Edit an event
  1. Find the event in Events and tap EDIT.
  2. Change its date, name, or event notes.
  3. Tap SAVE EVENT.

Event notes describe the overall outing. Session notes describe one individual run or heat.

Delete an event
  1. Tap EDIT beside the event.
  2. Scroll to Delete Event.
  3. Tap DELETE EVENT.
  4. Check the confirmation carefully, then tap YES, DELETE, or CANCEL to keep it.

Deleting an event also deletes its saved sessions. Export any recordings you want to keep first.

Choose your recording settings

Open Setup while disarmed. Settings are locked while recording is armed. Finish editing a number by leaving the field; settings save automatically.

Launch confirmation speed

This is the speed you must reach to confirm a launch. The default is 20 mph; the allowed range is 5–50 mph.

Once this speed is reached, timing is calculated back to the beginning of the launch. The selected speed is a confirmation threshold, rather than the point where timing simply begins.

If you never reach the selected speed, the launch will not trigger a recording. Choose a speed your intended run will comfortably reach.

Stop / next recording

This is how long you must remain stopped to close a recording and prepare for another launch. It is also used to recognize stationary readiness before launching.

Start with 3 seconds. A longer duration requires a longer stop. If you move again too soon, the app may not establish readiness or close the current session. Enter a positive duration.

Minimum completed laps

Selection Intended use
0 Keep partial laps and straight runs even when no complete lap is finished. Useful for initial testing.
1 Require at least one completed lap for the run to meet your selected minimum.
2 Require at least two completed laps for the run to meet your selected minimum.

When the required count is reached, the recording is kept from its original launch. Choosing 1 or 2 does not mean the beginning of the run is discarded.

A detected run that does not reach the selected minimum can still appear under the event with a note explaining that it did not meet the requirement.

Arm recording
  1. Open the event that should contain your recordings.
  2. Tap ARM RECORDING READY.
  3. Complete any location permission steps offered by the app.
  4. Remain stationary until the app is ready for launch.

Arming prepares automatic recording. It does not mean a riding session has already started.

Start a session

With the event armed, remain stopped for the configured duration, then launch and reach the selected launch confirmation speed. Lap Doctor starts the session automatically.

You do not manually mark the start line. It is established from the stationary position before launch. Begin somewhere you will cross again in the same direction when completing laps.

Record laps

Ride your circuit and cross the automatically established start line in the same direction as the launch. Lap Doctor identifies crossings and records lap times automatically.

If you start away from the circuit and never return through that starting line, you may record movement without completed laps. Use minimum completed laps 0 when testing a straight route.

Finish a session and start another

Stop and remain stationary for the configured stop duration. The app closes the current session and prepares for the next launch.

Leave the event armed to record another run. Once stationary readiness is established again, launch and reach the confirmation speed. Each run is saved as a separate session within the same event.

Finish recording for the day

Stop and allow the current session to close, then tap DISARM. You can then review sessions and change Setup values.

Record with the screen locked

Give Lap Doctor the required background/Always location access and Precise Location. Arm the event before locking the screen. Keep the phone securely positioned with a clear sky view.

Test this arrangement before relying on it at a track. Locking the screen and force-quitting the application are different actions; do not force-quit it during a recording.

Read the recording status
Status Meaning
WAITING FOR STATIONARY Remain stopped so the app can establish readiness.
RIDER STATIONARY The stationary waiting period is in progress.
READY FOR LAUNCH The stationary requirement has been satisfied.
LAUNCH DETECTED The launch has been recognized.
RECORDING A session is underway.
SESSION … — LAP … COMPLETED A lap has completed and recording continues.
RIDER STOPPED The app is closing the current session.
SESSION … COMPLETE The session has been saved.
READY FOR NEXT LAUNCH The app is prepared for another run.
View session results
  1. Disarm and open the event.
  2. Find the session under Sessions / Heats.
  3. Tap VIEW.
  4. Review completed lap count, fastest lap, top speed, and the lap table.

Scroll down for additional sections. Swipe left across a wide lap table to reveal columns farther to the right. Swipe right to return to the first columns.

Incomplete laps are marked separately from completed laps.

Edit a session name or session notes
  1. Open the session with VIEW.
  2. Scroll down and tap EDIT SESSION.
  3. Change the Session / Heat name or Session notes.
  4. Scroll down to SAVE SESSION to keep your changes.
  5. Use CANCEL EDIT to discard unsaved changes.

If the keyboard covers a control, dismiss the keyboard and scroll to it. The current interface uses the existing full session editor.

Remove an unwanted lap
  1. Open the session and tap EDIT SESSION.
  2. Find Lap Cleanup.
  3. Swipe left across the table to reveal the ACTION column on the right.
  4. Tap REMOVE beside the unwanted lap.
  5. Tap SAVE SESSION to apply your changes.

Removed laps are retained and marked as removed. They are excluded from the normal session results. Saving recalculates the visible-lap summary.

Restore a removed lap
  1. Open EDIT SESSION and find Lap Cleanup.
  2. Swipe left across the table to reveal the ACTION column.
  3. Find the lap marked REMOVED and tap RESTORE.
  4. Tap SAVE SESSION.

Use CANCEL EDIT instead if you want to abandon the current set of unsaved edits.

Delete an entire session
  1. Open the event and find the session.
  2. Tap DELETE on its session card.
  3. Confirm the deletion, or cancel to keep it.

Deleting a session removes the session and its laps. To exclude only an unwanted lap, use Lap Cleanup instead.

Export a recording

Open the event and tap the share icon beside the session. Use the iPhone sharing options to save or send the exported file.

Export any recordings you want to preserve before deleting their sessions or events.

Export options depend on your installed version. Detailed KML and Google Earth instructions are being prepared.

Use the Activity Log

Open Log to see timestamped activity messages. Use it to review the sequence of arming, stationary detection, launch, lap completion, and stopping.

When reporting a problem, note the event, session, approximate time, settings, and what you physically did. Include relevant log messages and an exported recording when available.

Improve GPS reception

Secure the phone with an unobstructed view of the sky. Avoid placing it beneath your leg or deep inside a pocket. Your body, buildings, trees, and other obstructions can reduce reception quality.

Check the route from a short test using your intended mount. A sensible mounting position matters even when the app has all required permissions.

GPS accuracy varies. A distorted exported path or inconsistent lap times should prompt a check of reception, mounting, and the actual recording.

Troubleshoot a recording that did not start

Check that the correct event is armed, location access is enabled, and the phone has a clear sky view. Remain stationary for the full configured duration, then reach your selected launch confirmation speed.

If the run will not reach that speed, lower the setting while disarmed. Use minimum completed laps 0 for a short or straight test. Check Log to see which stage was reached.

Troubleshoot missing laps

Check whether a launch was detected and whether the route crossed the original start line in the same direction. Review the minimum completed laps setting and any note on the saved session. Check phone placement and GPS quality.

A movement recording can exist without a completed lap, particularly on a straight run or a route that never crosses its starting line.

Troubleshoot a session that did not close

Remain completely stopped for the configured stop duration. If you move again before that duration passes, the session may continue. Check the status and Activity Log. Review the duration in Setup after disarming.
